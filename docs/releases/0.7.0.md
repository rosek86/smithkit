# Smithkit 0.7.0

This release groups visual configuration by element and adds optional constructor
mounting for charts and independent parameter scales.

## Configuration changes

- Trace styles use `line: { width, tolerancePx }` and `point: { radius }`.
  `setTraceOptions()` merges individual nested properties. `getTraces()` returns
  detached, readonly nested style snapshots.
- Grid and constant-circle styles use `line` and `text` groups. Appearance overrides
  group grid, scales, cursor, marker, and trace settings by visual element.
- Invalid or unknown style options are rejected before changing the chart.
- Chart defaults remain unchanged: standard impedance grid, labels visible,
  peripheral scales, zoom and cursor disabled, and no implicit markers.

These are breaking changes from 0.6.x. Update flat style keys using the
[migration guide](https://github.com/rosek86/smithkit/blob/v0.7.0/docs/migration-0.7.md).
No compatibility aliases are retained.

## Mounting and examples

```ts
const chart = new Smith('#chart', { appearance: { theme: 'dark' } });
const scales = new SmithScales('#scales', { theme: 'dark' });
const traceId = chart.addTrace(samples, {
  mode: 'both',
  line: { width: 2, tolerancePx: 0.5 },
  point: { radius: 3 },
});
```

Both constructors accept an `HTMLElement` instead of a selector. Deferred mounting
with `draw()` remains available. Scales stay independent of chart configuration
and events.

The demo and integration examples share updated styling, formatted source, and
syntax highlighting. The [API reference](https://rosek86.github.io/smithkit/api/)
and installed-package checks cover the new option shapes and constructor overloads.

```sh
npm install smithkit@0.7.0
```
