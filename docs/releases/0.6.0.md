# Smithkit 0.6.0

This release adds framework integration examples and searchable API documentation,
records browser verification, and fixes two public API edge cases ahead of 1.0.

## Documentation and integration

- Browse the searchable [API reference and guides](https://rosek86.github.io/smithkit/api/), linked from the demo and gallery.
- Use the React and Angular examples for mounting, updating configuration and data,
  events, resize, and cleanup. The components use the public library directly.
- Keep README focused on getting started, with a chart screenshot and separate migration guides.
- Check public API signatures in CI to make type and export changes visible during review.

## Compatibility and rendering

- Verify React StrictMode, Angular strict templates, and installed-package examples.
- Record native Firefox 114.0/114.0.2 and Safari 26.6 smoke checks on macOS 26.6.
  [Compatibility documentation](https://github.com/rosek86/smithkit/blob/v0.6.0/docs/compatibility.md)
  distinguishes tested environments from compilation targets.
- Improve Firefox label collision measurements and refresh font-relative offsets
  after resize so WebKit exports preserve the live label positions.

## API corrections

- `chart.toSvg()` and `scales.toSvg()` now apply the same output sizing and validation
  as calls with `{}`. Exports without options enforce the existing limit of 8192 px
  per side and 32 megapixels. For oversized mounted charts or scales, request a
  smaller SVG output size explicitly. The SVG's internal structure may differ;
  use the public export API rather than depending on its DOM layout.
- `Complex.from(re, undefined)` now defaults the imaginary component to zero,
  matching `Complex.from(re)` and the optional TypeScript signature.

Public signatures and chart defaults remain unchanged. Applications exporting
oversized SVG snapshots should account for the consistent size limits above.
The intended 1.x contract is described in the
[API review](https://github.com/rosek86/smithkit/blob/v0.6.0/docs/api-review.md);
this release remains on the 0.x line.

```sh
npm install smithkit@0.6.0
```

See the [demo and examples](https://rosek86.github.io/smithkit/) for runnable integrations.
